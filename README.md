### 💡 About Me

> **Bridging the gap between scalable web architecture and production-ready Artificial Intelligence.**

I am a Senior Full-Stack & Machine Learning Engineer currently pivoting deeply into **LLMOps**. I specialize in building end-to-end applications—from highly interactive Next.js interfaces to robust Node.js backends—while designing and orchestrating AI agents, memory systems, and predictive deep learning pipelines. 

* 🔭 **Currently Building:** Autonomous AI agents, custom orchestration loops, and LLM runtimes.
* 🧠 **Currently Learning:** Advanced RAG architectures, model evaluation infrastructure, and frontier agentic coding workflows.
* ⚡ **Engineering Philosophy:** Ship quickly, prioritize type safety end-to-end, and build reliable systems that scale.
