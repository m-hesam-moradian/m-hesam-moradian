<summary><b>⚙️ Setup Notes (read me once, then delete this section)</b></summary>

- **Username:** every widget above points at `m-hesam-moradian`. If that's not your GitHub handle, find-and-replace it throughout the file.
- **Live stats / streak / trophies / activity graph:** these are hotlinked images from public, free services (`github-readme-stats`, `github-readme-streak-stats`, `github-profile-trophy`, `github-readme-activity-graph`, `capsule-render`, `skillicons.dev`, `shields.io`) — nothing to install, they just work once the username is correct.
- **Contribution snake:** this one *does* need a tiny setup, since it's generated by a GitHub Action in your own repo:
  1. Create (or open) the special repo named exactly `m-hesam-moradian/m-hesam-moradian` (a repo with the same name as your username — GitHub uses this one as your profile README).
  2. Add the included `snake.yml` file to `.github/workflows/snake.yml` in that repo.
  3. Commit it, then run the workflow once manually from the **Actions** tab (or wait for the daily cron).
  4. It publishes the animated SVG to an `output` branch, which is exactly the URL already embedded above — so once it runs, the snake just appears.
- **Followers/profile-view counters:** update automatically, no action needed.
- Colors used throughout: `#00FFF9` (cyan), `#FF00EA` (magenta), `#9D00FF` (purple), `#0D1117` (near-black background) — change these hex codes anywhere you want a different accent.
